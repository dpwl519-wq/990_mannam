# 990 인연 · 직장인 소개팅 프로토타입

파일 하나로 도는 모바일 웹 프로토타입입니다. 빌드 없이 `index.html`을 브라우저로 열면 바로 실행돼요.
화면 스타일은 **조용한 파스텔 에디토리얼**(따뜻한 아이보리 종이 · 샌드 · 세이지 · 살구색 악센트 · 얇은 선 그림)로 맞춰져 있습니다.

## 열기
- `index.html` 더블클릭 (또는 `python3 -m http.server` 후 접속)
- 모바일에서는 화면 가득, 데스크톱에서는 가운데 휴대폰 프레임으로 보입니다.
- 제목·숫자는 Gowun Batang(명조), 본문은 Noto Sans KR을 Google Fonts에서 불러옵니다. 오프라인이면 시스템 글꼴로 자연스럽게 대체됩니다.

## 화면
- 상단 `사용자 | 운영자` 토글로 사용자 앱과 운영 콘솔을 오갑니다.

### 사용자 화면
| 탭 | 내용 |
| --- | --- |
| 오늘 | 사진 3장(점 인디케이터), 궁합 %, 우선순위 배지, 호감 보내기·건너뛰기(스와이프 가능) |
| 매칭 | 받은 호감 수락·거절, 보낸 호감 48시간 카운트다운·환불, 이어진 인연 |
| 대화 | 아이스브레이커 칩, 메시지 전송(상대 답장은 데모 자동 응답), 만남 체크·후기 |
| 프로필 | 사진 3장 업로드, 기본 정보, 선호 MBTI·우선순위, 안전 설정, 매칭권·포인트 |

### 운영자 화면
- `직장인 인증 심사`: 회사 메일/서류 제출 건 승인·반려(사유 입력)
- `신고 내역`: 신고 접수 확인, 이용 정지·기각, 정지 회원 복구

## 디자인 노트
- **색**: 종이 `#FAF6F0` · 샌드 `#E6D9C8` · 세이지 `#C9D6C9` · 살구 `#EABFA8`/`#D99B84` · 잉크 `#2E2825`
- **표면**: 1px 헤어라인(`rgba(46,40,37,.08)`)과 아주 옅은 확산 그림자. 두꺼운 테두리·블록 그림자 없음.
- **일러스트**: 카드 사진 자리는 이모지·만화 캐릭터 대신, 얇은 선 드로잉과 물감 번짐(wash)을 겹친 SVG입니다.
  - 모티프: `arch` `coffee` `book` `camera` `moon` `plant` `glass` `mountain` `tulip` `letter` `duo`
  - 프로필별 사진 모티프는 `PROFILE_ART`(스크립트 4번 섹션)에서 정합니다. 예: `dohyun: ['arch','coffee','book']`
  - 그림 생성은 `plateSVG(motif)`, 사진이 없을 때의 이름 아바타는 `avatarSVG(id, name)`(이름 첫 글자 모노그램)입니다.
  - 선 색·굵기·번짐은 `plateSVG()` 안의 `stroke-opacity`/`stroke-width`와 `ART_WASH` 값으로 조절합니다.
- **바꾸는 법**: 사진을 실제 이미지로 교체하려면 `cardHTML()`의 `.card-art` 부분을 `<img>`로 바꾸거나, `profile.photos[i].src`를 넣고 렌더링 한 줄만 고치면 됩니다. 지금은 `photos[i].caption`만 화면에 쓰입니다.

## 데모 시나리오 (3분)
1. **오늘** — `이준호` 카드에서 `호감 보내기` → 이미 호감을 보낸 상대라 바로 매칭(축하 효과).
2. **매칭** — `환불 데모` 버튼 → 48시간 무응답으로 990원 매칭권 1장 반환.
3. **대화** — 매칭된 `서지후` 방에서 `만났어요` → 후기 작성 → **+300P**.
4. **프로필 → 충전하기** — `포인트 사용` 체크 후 990원 매칭권 결제(포인트만큼 할인).
5. **프로필 → 직장인 인증** — 회사 메일(도메인 필요) 또는 서류 업로드 → `심사 중`.
6. **운영자 → 직장인 인증 심사** — `승인` → 사용자 화면의 인증 마크가 바로 바뀜.
7. **프로필 → 안전 설정** — `같은 회사 사람 보지 않기` 끄고 켜기, `010-5555-1234` 차단 → 오늘의 인연에서 사라짐.
8. **신고** — 카드 하단 `이 프로필 신고하기` → 운영자 `신고 내역`에서 `이용 정지`.

## 데이터
- `localStorage` 키 `blind-date-mvp/v3` 하나에 전체 상태가 저장됩니다.
- 초기화: 내 프로필 하단 `데모 데이터 초기화` (확인 시트).
- 같은 브라우저의 다른 탭과는 `storage` 이벤트로 실시간 동기화(운영자 승인 → 사용자 화면 마크).

## 백엔드 연결 지점
- `storage.load()` / `storage.save()` 두 함수만 API 호출로 바꾸면 됩니다.
- 프로필·매칭·대화·인증·신고 데이터는 모두 `state` 객체에 모여 있습니다.
- 궁합 계산은 `compatibility()`, 우선순위 판정은 `matchesPriority()` 한 곳에 있습니다.
- 사진은 프로필별 `photos[]` 배열이라 실제 이미지 URL로 교체하면 그대로 반영됩니다.

## 프로토타입용 목업
- 상대 프로필 사진: 라인아트 + 파스텔 번짐 SVG (실제 이미지 URL로 교체 가능)
- 대화 자동 답장, 인증번호 발송, 결제: 서버 없이 화면에서만 동작
- 전화번호 해시: 데모용 FNV-1a (실서비스는 서버에서 salt + SHA-256 권장)
